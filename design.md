# Home Tools 2 — locked design system

**Locked:** 2026-09-20 · **Source:** Hallmark `study` (image mode) of two references —
"Profile / Information Popup" and "Lumba VPN — SaaS VPN Service Desktop App".

This file is the system of record. Every page shares it; the diversification rules a
greenfield Hallmark build would apply are suspended, because this is one application,
not a set of landing pages.

## What was extracted

Both references are **dark, data-dense desktop app shells** — a narrow icon rail, a
secondary panel, and a large working pane. Neither is a marketing page. The DNA is the
same in both:

- **Surface over stroke.** Panels separate by lightness, not by borders. Borders, where
  they exist, are hairlines at ~6–8 % white.
- **Near-black, layered.** Body is almost black; each level up (surface → card →
  popover) steps up a few percent in lightness. No pure `#000`, no mid-grey panels.
- **One restrained accent.** A single chromatic colour marks the active/selected thing
  and nothing else. It glows; it does not flood.
- **Label-over-value.** Data is rendered as a tiny muted label above a white value,
  usually in a small card. Statistics get an oversized value with a small label.
- **Generous radii, quiet depth.** Cards ~14–16 px, chips and pills fully round.
  Elevation is a soft dark shadow, never a hard outline.
- **Typographic rhythm.** Bold headlines; small uppercase letter-spaced section
  headings; monospace for numbers and timers.

What we deliberately did **not** take: the references' exact accent hue (teal) and any
signature flourish. This is DNA, not a copy.

explicit overrides. `contrast: 'high'` is chosen for inspection-grade data density.

## Type

- **Family** — Inter for body and headings, with a metric-similar system fallback stack.
  System monospace for numbers. Nothing is loaded from a CDN; Inter resolves through the
  existing stack, and the fallbacks carry the design where it does not.
- **Scale** — base 14 px, ratio 1.2 (dense app rhythm, not a marketing scale).
- **Headings** — semibold; H1/H2 bold. Emphasis is carried by weight, never italics.
- **Labels** — small, muted, uppercase with letter-spacing for section heads;
  label-over-value for data.

## Shape, depth, motion

- **Radius** — base 4, multiplier 1.25 → element ≈10 px, container ≈15 px, pills full.
- **Depth** — soft dark shadow (`--shadow-low`, `--shadow-med`); elevation by lightness
  first, shadow second.
- **Motion** — 150 ms fast / 260 ms medium, eased. Hover and focus only; the accent glow
  marks selection. No orchestrated page entrances — this is a tool, used for hours.
- **States** — every interactive element carries default, hover, `:focus-visible`,
  active and disabled. Focus is always visible (keyboard access is a requirement, not a
  nicety).

## Component voice

- **Cards** are containers, not buttons. Dense rows use tables/lists, never card-wrapped
  list items.
- **Status** is a dot or token, **counts** are badges.
- **Empty states** say what to do next, in one sentence.

## Rules of the locked system

1. Tokens live only in the Astryx theme. If a value is needed that has no token, it
   becomes a token — never an inline hex or px.
2. Prefer an Astryx component and its props before any custom CSS. Existing bespoke CSS
   and inline `style={{…}}` are replaced as each surface is migrated.
3. No new dependency without a stated reason. The system is Astryx + Stylex + Tailwind
   tokens; motion is CSS.
4. Every migrated surface is verified in the browser at 320 / 375 / 414 / 768 px and at
   desktop width, in both light and dark, with the console clean.
